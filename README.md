# Host-Haven-Airbnb-inspired-
Host-Haven is an online hotel booking website designed to help users find and book comfortable stays with a smooth and simple experience.

🏨 Host Haven– Airbnb Inspired Booking Platform (MERN) 🔴 Live Preview (Demo) 🔗 Links:

Host Haven is a simple hotel booking web application built to practice full-stack development and understand how real-world booking systems work. The goal of this project is to create a practical platform where users can browse rooms and make bookings — without unnecessary complexity.

✨ Features 🏨 View available hotel rooms 📅 Basic booking functionality 🎨 Clean and minimal UI 📱 Fully responsive design (mobile-friendly)

🛠 Tech Stack 💻 Frontend HTML CSS JavaScript React.js ⚙️ Backend Node.js Express.js EJS (for server-side rendering) 🗄 Database
